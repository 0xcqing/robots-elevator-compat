This program sends one line of awkward robot-to-robot elevator small talk, and that line is the whole entry and nothing else. It writes the line to `entry.txt` in the output directory so a judge reads that one line and no more.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
